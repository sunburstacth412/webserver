## 💡 Managing your server

You can change how your server behaves using the settings menu. Click the icon in your system tray—the small area near your clock—to find the options.

* Port Number: You can pick a specific digital gate for your site. The default is 80 or 8080.
* Automatic Start: Tell the server to wake up when you turn on your computer.
* Logs: View a list of visitors to your site. This helps you track performance.
* Updates: The software checks for improvements automatically. Keep this setting on to ensure you have the fastest version.

## 🔐 Security and safety

The software includes built-in protection. It blocks common digital attacks before they reach your files. It only opens the path to the folder you selected. No other files on your computer face exposure. Always keep your Windows firewall active to ensure the highest level of safety. 

## 🔧 Fixing common issues

If the server refuses to start, check these items:

* Admin Rights: Some systems require you to right-click the icon and choose Run as Administrator.
* Port Conflict: If you run another web server program, close it before starting this one. Two programs cannot use the same port at the same time.
* Firewall: If your friends cannot see your site, check if your firewall allows the webserver program through.

## 📈 Performance tips

This server handles more traffic than traditional setups because it avoids background clutter. To keep it fast:

* Use smaller image files.
* Limit the number of heavy plugins on your site.
* Keep your main website folder on a fast drive, like an SSD.
* Restart the server once every few days to clear temporary memory.
